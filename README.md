# にじいろスライム

同じスライムをくっつけて色を育てる、ぷにぷに合体パズル。
2048 で「にじいろスライム」、4096 で「やみスライム」が生まれます。

▶ https://slime.fujiemon.dev/

## あそびかた
矢印キー / WASD、またはスワイプでスライムを動かします。
同じ数字のスライムがぶつかると合体して、色が一段派手になります。
